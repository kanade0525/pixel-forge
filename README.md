# Pixel Forge

画像を **16×16px 等のドット絵（ピクセルアート）** に変換する Web ツール。
自作ゲーム用のオリジナル素材制作を支援する目的で作成。

## 特徴

- **Lab 色空間での最近色マッチング**：k-means などの自動クラスタリングではなく、
  事前定義の**固定少色パレット**へ知覚的に自然に減色。
- **3つの減色/ディザ手法**を切替（すべて実装）：
  1. **ニアレストネイバー**（ディザなし・バンディング比較の基準）
  2. **組織的ディザリング（ベイヤー行列 2×2/4×4/8×8）**
  3. **フロイド–スタインバーグ誤差拡散**（serpentine 走査対応）
- **カラーバンディング低減**：ディザにより色段差を分散。
- **可変出力サイズ**（既定 16×16。16×28 キャラ / 32×36 ボス等も可）。
- **同梱パレット**：Game Boy(DMG/Pocket) / GBA風 / SNES風 / PICO-8 / Sweetie16 / Endesga32。
- **自作パレット読込**：HEX リスト / GIMP `.gpl`。
- クライアント完結（サーバ不要）。PNG 書き出し（原寸〜×16 拡大）。

## 使い方

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 本番ビルド
npm test         # ユニットテスト（Vitest）
npm run typecheck
```

ブラウザで画像を D&D → パレット/手法/サイズを調整 → プレビュー確認 → PNG 保存。

## アルゴリズム概要

### 色空間
sRGB(8bit) → 線形RGB → XYZ(sRGB/D65 行列) → **CIELAB**。
最近色判定は Lab で行う。色差は **ΔE76（既定・高速）** と **CIEDE2000（高精度）** を選択可
（CIEDE2000 は Sharma et al. の定式に準拠、テストで参照値検証済み）。

### 縮小
既定は**面積平均（ボックスフィルタ）**。平均は**線形光**で行い（プリマルチプライ・アルファ対応）、
ガンマ補正済みの正しい縮小になる。任意で**ニアレスト**。

### ディザ
- **ベイヤー**：各画素で最近2色 `c1,c2` を求め、Lab 上の射影比率 `t` をベイヤー閾値と比較して振り分ける
  （任意パレット対応。誤差を溜めないためタイル境界でも安定）。
- **フロイド–スタインバーグ**：作業は**線形RGB**（エネルギー保存）、色選択のみ Lab。
  残差を近傍へ 7/16, 3/16, 5/16, 1/16 で拡散。serpentine 走査で縞を低減。
